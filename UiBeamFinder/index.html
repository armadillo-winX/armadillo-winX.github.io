ういビーム検出器
これは何?
ういビーム検出器およびういビーム検出器 CLI は， テキストから縦読み，斜め読みを含むういビームを発見するためのライブラリとアプリケーションです． ういビーム検出器がういビームを検出するためのライブラリであり， このライブラリを搭載し，コマンドラインからういビームを検出するアプリケーションがういビーム検出器 CLI です．
ういビームとは，イラストレーターであり，個人で VTuber としても活動されている しぐれうい 氏のファンの間でのミームです．詳しくは ういビーム | pixiv 百科事典 を参照．
使い方
ういビーム検出器 CLI で，テキスト中のういビームを探索できます． 詳しい使い方は， ういビーム検出器の GitHub リポジトリ を参照してください．
動作環境
動作環境は，.NET Runtime 10.0 がインストールされている Windows 環境を想定しています．
動かすには Microsoft の .NET Runtime 10.0 が必須です． .NET 10.0 ランタイムのダウンロード からダウンロード，インストールしてください．
